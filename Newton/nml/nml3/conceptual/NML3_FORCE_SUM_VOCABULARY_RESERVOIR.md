# NML3 Force-Sum Vocabulary Reservoir

**Status:** broad vocabulary collection  
**Project:** VD Newton / NML3  
**Purpose:** collect words and phrases that already carry useful residual meaning around the force-sum law, without yet deciding which should become formal VD headwords.

This note deliberately keeps a wide net. Some terms overlap, some are historically old-fashioned, some are modern pedagogical language, and some are potentially dangerous because they carry multiple meanings. The aim is not to choose terminology yet. The aim is to preserve the available semantic material.

## 19. Potentially useful but semantically dangerous words

### `component`
Useful reaction: one part of a larger resultant.  
Danger: coordinate component of one vector.

### `contributing-force`
Useful reaction: one physical contribution to the net result.  
Danger: anything written as a summand therefore counts as a physical force.

### `superposition`
Useful reaction: distinct effects coexist and add.  
Danger: strong quantum-mechanics association and may sound purely mathematical.

### `total`
Useful reaction: everything added together.  
Danger: says little about how the relevant “everything” was identified.

### `net`
Useful reaction: result after additions and cancellations.  
Danger: almost entirely output-facing.

### `resolution`
Useful reaction: split one vector into mathematical components.  
Danger: historical mechanics can phrase the components as “forces,” encouraging reification.

### `force system`
Useful reaction: several forces treated together.  
Danger: engineering usage can import moments, couples, and extended-body machinery.

### `free-body diagram`
Useful reaction: one target; list the forces acting on it.  
Danger: can silently import the habit of assuming the list is already correct.

## 21. Current use

For now, this document should function as a **word reservoir**.

A later pass can ask of each promising term:

```text
What reaction is already installed by this word?
What part of NML3 could use that reaction?
What misleading baggage does the word also carry?
Is the reaction culture-installed strongly enough to rely on in a residual?
Would the word be better as a headword, residual phrase, exercise label,
teacher-facing term, or anti-misconception contrast?
```

No terminology decision is implied by inclusion here.
